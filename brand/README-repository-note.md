# Note on this folder

`README.md`, `asset-manifest.json`, `source/`, `vector/`, `print/`, and the two
`*.template.*` files are copied verbatim from `macks-studios-logo-package-v1.zip`
(version 1.0.0). Paths inside the package README refer to the package layout, not this
repository. The production web set lives in `public/assets/brand/` and is listed in the
root README. The generated PNG, WebP, background, and preview exports were deliberately
not copied; they are reproducible from the SVG masters here. Also: the package README
mentions `public/macks-studios-logo-transparent.png`, which the package does not contain.
