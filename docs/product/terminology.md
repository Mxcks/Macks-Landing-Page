# Terminology

Internal and public terms used in Macks Studios material, with the public-site wording
to use. Definitions are taken from the reference prototype and the content package
only. Where no definition exists, the term is marked undefined.

| Term | Source definition | Public-site treatment |
|---|---|---|
| Studio Foundation | Offer-level working name for the client engagement (alignment brief 2026-09-23). | Used publicly as the offer name, provisionally. Naming split pending Max's approval. Never used for code or domain concepts. |
| Presence Package | Make the offer easier to understand across the places customers find the business. | Internal deliverable name. Describe the outcome; name optional. |
| Product Suggestion Map | Identifies which small products or capabilities could remove friction from the next step. | Internal deliverable name. Describe the outcome; name optional. |
| Essential Platforms | The tools that fit the actual workflow, account readiness, and customer journey. | Internal deliverable name. Describe the outcome; name optional. |
| Opportunity Stack | A practical sequence of opportunities, each tied to a real need. The "200+" library size is unconfirmed. | May be used publicly without the count. |
| Discovery | Step 01: talk through the business, documents, current tools, and desired changes. | Public. |
| Foundation Map | The issued, client-facing diagnostic and specification document created from accepted intake and analysis (alignment brief). Contains current-state analysis, evidence-backed findings, linked recommendations, risks and constraints, prioritized next steps. Not pricing, terms, agreement mechanics, or build work. | Public, exact name, step 02. No variants (Studio Map, Foundation Report, etc.). |
| Proposal | Separate commercial artifact: offered scope, pricing, payment terms, client decision, based on Foundation Map recommendations. | Public, step 03. Never merged with Foundation Map. In the connected-systems flow the client's own document is called "Quote" to avoid the clash. |
| Build | Downstream delivery after the Proposal and later commercial gates. | Not a public stage. One-line note after Proposal only. |
| Void Map | Internal research and analysis tool. | Never public. |
| Studio Discovery call | The bookable call that is the site's primary conversion (stage 01). Not the diagnostic; the diagnostic is the Foundation Map. | Public. Always "Studio Discovery call" on the site. |
| Inquiries / Booking / Payments | Example connected capabilities a business presence can include. | Public, as examples, not as products. |
| Connected business systems | Owner-brief phrase for the practical systems a presence links to. | Public. |
| Discovery guide | The optional browser-only questionnaire on the public page. | Public. Must never be described as sending anything unless sending is configured; then only "Send my answers" sends, and only on the visitor's click. |
| Seven business systems | Referenced in the content package README as "the backbone." | **Undefined** in supplied material. Do not use until defined. |
| Client management system | The separate post-lead application (engagements, proposals, invoices, projects, handoff). | Not referenced on the public site. |
