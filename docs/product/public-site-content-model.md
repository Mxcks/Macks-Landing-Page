# Public site content model

Status: approved section order from the Phase 1 audit (2026-09-23). Implemented in Phase 5;
see `content-source-audit.md` for where each line came from. Each row records where the section's content comes from so a future
editor knows what is source-backed and what is new.

Conversion journey the page serves:

visitor → understands Macks → recognizes their problem → understands the kind of system
Macks helps create → understands the process → gains confidence → books a Studio
Discovery call.

| # | Section | Purpose | Content source |
|---|---|---|---|
| 1 | Header | identity, two anchor links, booking CTA | new; logo from `public/assets/brand/` |
| 2 | Hero | say in seconds what Macks does, that it is broader than a website, and what the next step is | prototype headline "Turn scattered systems into a clear next step." and its supporting paragraph; may be adapted |
| 3 | Does this sound familiar | let the visitor recognize their situation | owner brief situations (website leads nowhere, disconnected inquiries, manual booking, disconnected payments, scattered information, no clear order); written with the PAS discipline in `content-guidelines.md` |
| 4 | Connected-system example | make "connected systems" tangible | implemented as a seven-step client journey (inquiry to follow-up) per the Phase 5 instruction; the prototype's tabbed browser mock-up was not rebuilt (it needed fake UI data and an icon CDN) |
| 5 | Studio Foundation (offer, provisional name) | explain the engagement and what the Foundation Map gives the client | prototype `#studio` heading and lede, rewritten per `studio-foundation-alignment.md`; no "200+" count |
| 6 | How it works | Discovery, Foundation Map, Proposal; one-line Build note | Discovery from the prototype; Foundation Map and Proposal rewritten from the alignment brief boundary |
| 7 | Discovery guide (optional) | help the visitor organize what to discuss before booking, copy a summary | four questions specified by the owner (2026-09-23); browser-only, no contact fields; not intake, not the Foundation Map |
| 8 | Final CTA | one sentence, one booking button, privacy line | new |
| 9 | Footer | copyright, Arlington, Texas, booking link, About the studio link | both existing files |

## Deliberately excluded

- The prototype's design-only inquiry form (it did not send anything).
- Example payment ledger ("$150 Paid", "$500 Paid") and any pricing.
- Login, signup, reservation, or any client-system behavior.
- Name, business, and email fields inside the guide.
- Hotlinked logo, Google Fonts, and the Lucide CDN from the prototype.

## Copy status

All sections written in Phase 5 and aligned to the alignment brief in the Phase 6 alignment pass. Guide questions implemented per the owner's specification.
